# Change Design

Apply a new visual style to the entire website.

## What This Action Does

- Updates design tokens in style.css (colors, fonts, spacing)
- Adjusts component styles to match the new direction
- Preserves all content while transforming the visual identity

## Trigger

User requests a visual change to the overall site design.

## Example Prompts

- "Make this site feel more luxurious and premium"
- "Switch to a dark theme with gold accents"
- "Use a more modern, minimal aesthetic"
