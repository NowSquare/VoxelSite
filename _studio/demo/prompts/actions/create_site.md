# Create Site

Generate a complete, professional website from a text description.

## What This Action Does

- Creates all page files (index.php, about.php, contact.php, etc.)
- Generates shared partials (_partials/header.php, nav.php, footer.php, schema.php)
- Writes the CSS design system (assets/css/style.css)
- Writes interactive JavaScript (assets/js/main.js)
- Configures SEO metadata on every page

## Trigger

User describes a business or website they want to build.

## Example Prompts

- "Build a website for my bakery, The Baker's Table"
- "Create a portfolio site for a freelance photographer"
- "I need a landing page for my SaaS product, CloudSync"
