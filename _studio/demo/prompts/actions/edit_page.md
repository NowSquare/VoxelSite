# Edit Page

Make targeted changes to a specific page based on user instructions.

## What This Action Does

- Modifies the content, layout, or styling of a single page
- Preserves existing structure while applying requested changes
- Updates related partials if navigation or footer changes are needed

## Trigger

User describes a change to a specific page (e.g., "update the hero section").

## Example Prompts

- "Make the hero section bigger with a background image"
- "Add a testimonials section to the homepage"
- "Change the contact form to include a phone number field"
